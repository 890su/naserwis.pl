# Approved logo — 31 October 2026

The owner selected the custom S with two radio-signal bands after three rounds
of logo-design review, then requested publication on both sites. Artwork is
outlined SVG with Manrope lettering and the existing cobalt #1d5bd0 / ink
#18212c palette. The commercial offer and navigation remain unchanged.

The owner subsequently requested the previous lettering with the new symbol.
Website headers now pair the symbol-only SVG with the original native Manrope
wordmark: `Na` in inherited ink, `Serwis` in #1d5bd0, weight 800, 28px type
(22px below 361px, 20px below 341px), and -0.03em tracking. A 34/30/24/20px symbol and
8/5px gap keep its visual weight below the name. The full horizontal masters
remain available for independent artwork; they are not used in the header.

Versioned assets live in `public/assets/brand/20261031/`; earlier immutable
assets are retained. The horizontal SVG viewBox trims transparent presentation
padding while preserving the approved contours. Fixed symbol dimensions reserve
the header space. All four locales keep their localized homepage link and
accessible brand name. Mobile rules preserve language and menu controls.

`scripts/apply-branding.mjs` runs in the technical generator after shared
headers and the redesign. It applies the logo and web-icon links to every HTML
page, renders the matching social image and retains the legacy root favicon
fallbacks. Run `npm run technical:generate` after changing its inputs.

The icon set contains SVG, multi-size ICO, Apple touch, regular and maskable
app icons. Its manifest uses relative icon paths. Social metadata and the
existing LocalBusiness image point to the versioned 1200×630 brand plate.
URL, title, description, canonical, hreflang and sitemap dates are preserved.

Manrope's SIL OFL licence is in `docs/brand/Manrope-OFL.txt`. The source font
is not required to display the outlined wordmark.
