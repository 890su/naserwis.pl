# Локальные бизнес-услуги NaSerwis — 26.10.2026

Владелец поручил локализовать бизнес-услуги внутри NaSerwis, сохранив текущий
стиль, короткие тексты и существующую форму с примерами по теме страницы.
ITBIZ параллельно переделывают отдельно; этот репозиторий его не изменяет.

## Структура

| Назначение | PL URL | Объём |
| --- | --- | --- |
| Выбор бизнес-задачи | `/dla-firm/` | Пять услуг и общая форма |
| Авария сети | `/dla-firm/awaria-sieci/` | Рабочие места, сеть организации, согласование перерыва |
| Видеонаблюдение | `/dla-firm/monitoring/` | Изображение, запись, доступ уполномоченного сотрудника |
| Офисная LAN | `/dla-firm/sieci-lan/` | Точки, трассы, маркировка, приёмка |
| Офисный Wi-Fi | `/dla-firm/wifi/` | Покрытие, точки доступа, гостевая сеть |
| Помощь офису | `/dla-firm/obsluga-it/` | Рабочие места, принтеры, согласованный объём поддержки |

Все маршруты имеют RU/UK/EN-эквиваленты с теми же slug. Общее SEO Wi-Fi/LAN/CCTV
остаётся у существующих страниц. Новые страницы раскрывают рабочий сценарий
организации кратко, без копирования длинного каталога и статей.

## Поведение

- Меню, мобильное меню, подвал, главная и бизнес-ссылки существующих услуг ведут
  на локальные страницы. Внешний переход и подпись ITBIZ убраны из этих блоков.
- Новый раздел использует существующий тёмный заголовок, Manrope, синюю кнопку,
  адаптивную форму и контактные каналы.
- Форма сохраняет IDs, поля, endpoint, согласия, подтверждение отправки и
  повторную попытку. Примеры выбираются по контексту страницы.
- В атрибуцию передаются текущая landing page и отдельный код бизнес-услуги.
  Названия событий и идентификаторы Google Ads сохранены.
- Цены: условные 200 / стандартный выезд 250 / следующий час 150 zł. Условия
  короткой близкой задачи видны; остальные условия раскрываются по запросу.
- Существующие H1/title/description/canonical/hreflang общих услуг сохранены.
  Их FAQ об организациях теперь подтверждает локальный приём NaSerwis; видимый
  ответ и schema обновлены синхронно.

## Источники и сборка

`scripts/business-copy.mjs` — тексты и примеры; `scripts/build-business-pages.mjs`
— генерация; `scripts/business-links.mjs` — маршруты; `public/business.css` —
небольшие дополнения к действующим стилям. `npm run business:generate` входит
в общий идемпотентный конвейер, поэтому другие генераторы сохраняют раздел.

## Проверки и статус

Статическая проверка охватывает 24 новых маршрута, наличие форм, уникальность
DOM IDs, локальные ссылки, языковые переключатели, schema, sitemap и цены.
Браузерная проверка проверяет контекст примеров, отправку с повторной попыткой,
адаптивное размещение и сохранение данных при смене ширины.

Результат: `npm run check` — пройден на 73 HTML-страницах; `npm test` — 13/13;
43 браузерных сценария — пройдены. Включена проверка единственной основной
конверсии после успешного ответа формы. Макеты просмотрены на 390 и 1440 px.
Title/description/H1/canonical/hreflang всех 20 прежних коммерческих страниц
сопоставлены с HEAD и сохранены. В прежнем браузерном тесте стабилизирован выбор
движущегося примера через существующую кнопку раскрытия списка.
Повторная генерация дала идентичные 73 HTML-файла, asset manifest и sitemap.

Владелец разрешил публикацию 26.10.2026 после просмотра локальной версии.
Формы начинают с описания без отдельного заголовка. В одноколоночном hero
(до 900 px включительно) крупный телефон стоит под формой по центру, а
дублирующая ссылка рядом с WhatsApp/Telegram скрыта. В двух колонках телефон
остаётся рядом с заголовком. Дополнительная приёмка: 21 браузерный сценарий.

Публикация выполняется через существующий Git/Cloudflare Pages; точная ревизия,
deployment и результат проверки рабочего домена сохраняются в локальном
`outputs/publication-business-20261026/publication.json`. Успех выкладки
подтверждается отдельно от разрешения владельца. Тестовые запросы
перехватываются в браузере, реальные заявки при QA не отправляются.
