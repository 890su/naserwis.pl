# Общая панель согласия для Chatwoot — 26.09.2026

Состояние: исправлено и проверено локально; публикация разрешена владельцем
26.09.2026. Результат публикации проверяется по Cloudflare Pages и рабочему сайту.

Причина жалобы: `requestSupport()` открывал расширенные настройки общей
панели (`show(true)`). Закрытие крестиком или Escape при отсутствии прежнего
выбора записывало все необязательные категории как выключенные. Поэтому
после закрытия баннер больше не появлялся, хотя явного выбора не было.

Изменения в `public/consent.js` и `public/contact-ui.js`:

- Кнопка чата при отсутствии разрешения открывает компактную общую панель.
- Кнопки: принять все, только обязательные, настроить. «Только обязательные»
  означает отказ от всех необязательных категорий; дублировать этот результат
  ещё одной кнопкой не требуется.
- Закрытие настроек/Escape ничего не сохраняет. Если выбора ещё нет,
  возвращается компактный баннер; уже сохранённый выбор остаётся прежним.
- Отмена также снимает ожидание открытия чата, чтобы последующий выбор
  согласия сам по себе не открывал ранее отменённый чат.
- Настройки позволяют отдельно разрешить чат без аналитики и рекламы.
- Все четыре локали обновлены. Загрузка Chatwoot до разрешения по-прежнему
  заблокирована; обязательность конкретных хранилищ Chatwoot не переоценивалась.

Проверено: синтаксис обоих JS-файлов, `npm run check`, все 12 unit-тестов.
В Chrome на локальной RU-странице воспроизведены: чат до выбора согласия,
отмена настроек с возвратом баннера, перезагрузка без выбора, явный выбор
только обязательных, его сохранение после перезагрузки, повторное открытие
настроек. Во всех этих сценариях Chatwoot SDK не загружался.
Формы не отправлялись, звонки/сообщения не выполнялись.

Внешний чат и вариант «принять все» в этом проходе не запускались, чтобы
не создавать производственные события измерения из локальной проверки.
Владелец разрешил публикацию сообщением «публикуй». Публикация осуществляется
через существующую Git/Pages интеграцию; результаты проверки фиксируются
в журнале выпуска.
